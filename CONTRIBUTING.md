# Contributing

Thanks for looking at Creator Studio.

## Development

1. Clone the repository.
2. Edit files in `xdc-src/` (no bundler, no runtime dependencies).
3. Build: `python3 build.py`
4. Test the `.xdc` in Delta Chat.

## Conventions

* Vanilla HTML / CSS / JavaScript.
* UI strings live in `xdc-src/i18n.js` (English + Spanish only).
* Keep comments in English; avoid historical version tags in comments.
* Prefer small, focused commits on feature branches.
